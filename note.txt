X -> {F | G | U | X}

    X -> F => no relevant path but important prop(s) at the end 
    X -> G => the entire path contains important prop(s)
    X -> U => the path contains important prop(s) along the way but also at its end points
    X -> X => immediate next prop(s) is more important than future props

F ->  {F | X}

    F -> F => consequent is/are important and nothing along the path is of grater relevance
    F -> X => parent prop(s) is/are more important than consequent

    G -> G => path prop(s) match, thus we keep the same formula 
    G -> F => path prop(s) fails, consequent is imoprtant and parent prop(s) is/are irrelevant

    G -> X => path prop(s) fails and parent prop(s) is/are more important 
    G -> U => path prop(s) fails but parent prop(s) is/are also important
